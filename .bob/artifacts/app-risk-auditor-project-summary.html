📱 App Risk Auditor

Hackathon PS-01 · Mobile Security Track · Team CTRL-ALT-ELITE

Answers three questions every phone user should ask: Which apps can do the most harm? Why? What do I do about it — right now?

What it does

A fully on-device Android app that scans every installed package, extracts permissions and special OS-level access, groups them into 9 categories, and assigns each app a 0–100 risk score with plain-language reasons — no jargon, no server, no root needed.

Risk Bands

ScoreBandMeaning
0–24LowNormal app; no sensitive access of concern
25–49MediumSome permissions worth knowing about
50–74HighSignificant sensitive access; review recommended
75–100CriticalDangerous capability combination — act immediately

Architecture

Tech stack

  • Kotlin + Jetpack Compose + Material 3
  • MVVM · ViewModel · StateFlow
  • Single module · minSdk 26 · targetSdk 35
  • Standard Android SDK only — no extra libs

Key files

  • RiskEngine.kt — pure Kotlin scorer
  • SpecialAccessDetector.kt — 6 access types
  • PermissionCategorizer.kt — 80+ permission map
  • AppDetailScreen.kt — full detail UI

Privacy guarantees

  • 100% on-device · zero network calls
  • No INTERNET permission in manifest
  • No root, no ADB at runtime
  • No user data ever leaves the device

Special access detected

  • Accessibility services (active)
  • Device administrators (active)
  • Notification listeners (active)
  • Overlay / draw-over-apps
  • Install packages access
  • Usage stats access

3-Minute Demo Flow

  1. Home screen (30 sec) — Device summary header: 4 band-count cards (Critical/High/Medium/Low) + scrollable access-type chips (Location: 12, Network: 34…). Show filter chips → tap "Critical".
  2. Top Critical app (60 sec) — Tap it. Score panel (e.g. 87 · Critical). Read 3 plain-language reasons aloud. Highlight the combination rule reason if present.
  3. Action buttons (30 sec) — Scroll to bottom. Tap "Open App Settings" → system settings opens. Return. Show "Uninstall App" button.
  4. Combination rule (30 sec) — Show the SMS + internet + boot + sideloaded warning, or switch to the High filter and show multiple flagged apps.
